# 分层逻辑与选区审美

核查日期：2026-10-29。没有统一适用于所有闪卡工艺的“三层国际标准”；以下是印刷服务商公开指南支持的常见做法。范围是镭射底材配局部白墨和彩印；烫箔、透镜翻转卡和立体浮雕是另外的工艺。

## 已核实的一手资料

**S1：[StickerHD：How Should I Prepare White Ink Artwork?](https://stickerhd.com/en/faq/holographic-stickers-and-cards/indicate-white-ink)**

该商家用独立白墨层、K100 标识覆盖区域，支持不同覆盖量；建议选择性铺白，深色下不一定需要白墨。其例子保护角色和主体颜色，让边框、光束及装饰点露底。细节、白边和纹理底材需打样，满白未必完全消除某些底纹。该厂的缩边数值仅用于其工艺，不作为通用设置。

**S2：[Uproar Design & Print：Holographic Foil Print Setup](https://uproar.art/blogs/resources-and-press-releases/setup-holographic-foil-vfx-uv-printing)**

该商家区分 White、Color 与可选 Varnish。白墨遮底；彩色直接印在反光底上产生带色金属效果；两层都空则露原始底材。光油有独立效果。其白墨蒙版要求二值，说明灰阶能力不能跨厂假设；图层命名和边缘补偿按其设备规范。

来源只支持工艺与上述示例；以下具体元素审美是本技能依据画面作出的建议，不冒充行业强制规范。其他厂家可能采用不同纸张、印法和专色编码。

## 一、区分三种“层”

1. **实物功能层**：底材→白墨→彩色→可选光油或覆膜。透明保护膜与局部光油不能简单互换。
2. **设计语义分组**：人物、背景、标题、装饰、光效，可分组编辑；不代表每组需要一张印刷版。
3. **印刷分色文件**：彩色版、白墨版；有额外工艺才加光油/烫箔/刀线等独立版。不要无端为新手增加工艺。

## 二、先定义目标效果

| 目标 | 彩色层 | 白墨层 | 处理含义 |
|---|---|---|---|
| 保持常规颜色/肤色 | 保留 | 覆盖 | 尽量减少反光底影响，实物依材料 |
| 保留原色的局部炫彩（默认） | 保留 | 选区留空 | 彩色与镭射底共同呈现 |
| 直接露原始镭射底 | 选区也留空 | 选区留空 | 原色消失，须单独说明并确认 |
| 纯白文字/星点 | 彩色白通常不等于白油墨 | 覆盖 | 保持白色的目的与露底反光有取舍 |
| 深色细节 | 保留 | 依效果与厂家建议 | 深色可能已遮反光，去白不保证变亮 |
| 柔和渐变反光 | 保留 | 灰阶仅在厂商支持时 | 默认工具保留边缘抗锯齿，不代表工厂支持任意半白渐变 |

当前辅助脚本只实现默认“彩色保持、选择性去白墨”。用户选择直接露底时，另制并单独命名彩色变体，经确认后交付，始终保留原图与完整彩色母版；不能谎称默认脚本已经支持这项制作。

## 三、哪些元素适合选区

以下是审美起点，要结合实际图像与用户目标调整：

| 元素 | 建议 | 边界/取舍 |
|---|---|---|
| 大标题、徽标、几何边框 | 常用候选，选择主要部分 | 保留字腔与阅读性；不默认让所有细字发闪 |
| 金属徽章、饰件、武器、装甲高光 | 常用候选 | 追随材质和光向，保留暗部结构 |
| 星光、光环、能量轨迹、背景装饰 | 常用候选 | 控制主次，整片发光不等于整片挖空 |
| 天空、水面、路面等背景 | 可局部使用 | 考虑色彩变化与人物分离，避免抢主体 |
| 衣服花纹、发丝亮边、瞳孔亮点 | 条件候选 | 原图清楚、实际印刷尺寸足够才选；脸部附近格外谨慎 |
| 脸、肤色、眼白与主要表情结构 | 默认保护 | 除非用户明确追求特殊效果，不主动全面透底 |
| 说明文字、版权小字、二维码、条码 | 默认保护对比与可读性 | 编码类以最终印刷尺寸测试，不能以闪光牺牲功能 |
| 大面积黑、深发、暗部 | 不作为优先炫彩区 | 深墨可能遮闪；铺白与否由实物目标及厂家意见决定 |
| 烟雾、玻璃、复杂半透明渐变 | 谨慎，先小样 | 平面彩图不能可靠反推全部材质透明度 |
| 极细线、碎发、噪点、微小孤岛 | 不宜逐点硬抠 | 以成品尺寸和厂商最小细节能力判断 |

不要机械按“所有亮色/所有白色/所有背景”选区，也不规定所有图都必须只闪某个百分比。反光区域应有主焦点、连贯节奏、明确材质逻辑；保护区的目的也要在标记图说明。对用户明确要求的全闪风格，应说明颜色变化后按其目标做方案。

## 四、预览与生产检查

标记图只显示选择范围；套位图只显示像素位置；模拟炫彩图只帮助审美判断。真实底纹、角度、光源、遮盖力和覆膜效果仍需实物打样。别把模拟颜色当成最终承诺。

厂商有时要求白墨缩边以减轻套准白边，但没有通用的固定像素或毫米值。特别细小元素缩边可能消失；使用实际尺寸、分辨率和厂商容差再决定。抗锯齿、灰阶白墨和半透明材质也应分别核对。
